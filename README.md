# Propuesta Técnica: Cívica Digital

Este repositorio contiene el código fuente de la landing page para la propuesta técnica de modernización y digitalización integral del sistema Cívica del Metro de Medellín. (Caso de referencia: M00746243).

## Características

- Construida con Next.js 14 (App Router)
- Estilizada con Tailwind CSS (Paleta de colores Metro de Medellín)
- Animaciones e interacciones con Framer Motion
- Iconografía de Lucide React
